# Lockheed SR-71A — USAF 61-7972

Original OpenFlightSim geometry, UVs, textures and reconstructed rig authored
through Blender MCP. No third-party model, commercial-game content or photo
texture was incorporated. Public references guided dimensions and visual shape;
see `docs/M3_67_SR71_VALIDATION.md` for reference and approximation records.

Runtime files are the four `sr71_lod*.glb` files. LOD0 embeds its PBR textures;
LODs 1–3 reuse those materials by name and contain no duplicate image payloads.
The PNG directory contains editable source textures, not an additional runtime
requirement. The editable, packed Blender source is `output/SR71_61-7972.blend`.

Adwaita Mono Bold was used to rasterize original maintenance labels into images.
No font binary is included. Its SIL Open Font License and notices are retained
in `Adwaita-Font-License.txt`. National markings and historical insignia are
reconstructed identification elements, not a claim of endorsement.
